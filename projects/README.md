# Impact OS — Projecten

Elke klant of domein krijgt een eigen map onder `projects/`.  
Een project is herkenbaar aan zijn **SKILL.md** — daarin staat alles wat Hermes moet weten om voor die klant te werken.

## Een nieuw project toevoegen

```bash
cp -r projects/sjabloon projects/nieuwe-klant
# Vul projects/nieuwe-klant/SKILL.md in
```

## Structuur per project

```
projects/onze-nieuwe-klant/
├── SKILL.md              ← Merk, toon, doelgroep, content-thema's
├── content/              ← Gegenereerde blogs, artikelen, teksten
├── prospecting/          ← Leads + outreach (run-YYYYMMDD-HHMMSS/)
└── assets/               ← Logo's, afbeeldingen, voorbeelden
```
